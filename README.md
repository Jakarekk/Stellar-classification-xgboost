## About the Project
The `assessment` folder contains the initial stellar classification performed using **XGBoost**. 

Currently, the main focus of this project is evolving into a comprehensive **benchmark**, comparing multiple gradient boosting methods, including **XGBoost, LightGBM, and CatBoost**.
